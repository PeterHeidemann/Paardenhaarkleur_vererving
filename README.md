# Paardenkleuren & erfelijkheid

Interactieve simulator voor de erfelijkheid van vachtkleuren bij paarden. Kies een merrie en een hengst en zie welke kleuren hun veulen kan krijgen, met de kans per kleur en een Punnett-vierkant per gen.

Het model gebruikt drie genen:

- **Extension (E/e)** – zwart of rood pigment
- **Agouti (A/a)** – waar het zwarte pigment zit
- **Cream (CR/cr)** – verdunning (palomino, valk, cremello, perlino, …)

## Bekijken

Open `index.html` in een browser, of bekijk de online versie via GitHub Pages.

## Projectstructuur

```
index.html      pagina
css/style.css   opmaak
css/masks.css   silhouetten van het paard
js/app.js       rekenlogica en interactie
```

Geen build-stap of installatie nodig: het is gewone HTML, CSS en JavaScript.

## Beperkingen

Vereenvoudigd model. Schimmel, vaal (dun), zilver, champagne en bonte patronen zijn niet meegenomen.
